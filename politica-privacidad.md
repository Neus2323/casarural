# Política de Privacidad

## Introducción

La presente Política de Privacidad tiene como finalidad informar sobre el tratamiento de los datos personales recopilados a través de este sitio web.

## Datos recopilados

Este sitio web puede recopilar datos personales a través de:

- Formularios de contacto
- Enlaces de correo electrónico
- Comunicación mediante WhatsApp

Los datos recopilados pueden incluir:

- Nombre
- Dirección de correo electrónico
- Número de teléfono
- Información facilitada voluntariamente por el usuario

## Finalidad del tratamiento

Los datos personales serán utilizados únicamente para:

- Responder consultas realizadas por los usuarios
- Gestionar solicitudes de información o reservas
- Mantener la comunicación con los clientes

## Conservación de los datos

Los datos se conservarán únicamente durante el tiempo necesario para cumplir con la finalidad para la que fueron recopilados.

## Protección de la información

Se aplican medidas de seguridad adecuadas para proteger la información personal de accesos no autorizados, alteraciones o pérdidas.

## Cesión de datos

No se cederán datos personales a terceros salvo obligación legal.

## Derechos del usuario

El usuario podrá ejercer sus derechos de:

- Acceso
- Rectificación
- Supresión
- Limitación del tratamiento
- Oposición

Para ello podrá contactar mediante el correo electrónico:

**info@casaruralcadiz.com**

## Cookies

Este sitio web puede utilizar cookies técnicas necesarias para el correcto funcionamiento de la página.

## Modificaciones

El titular se reserva el derecho a modificar esta política de privacidad para adaptarla a novedades legislativas o cambios en el sitio web.
